# Belajar Python - Hand Tracking & RetroLens Filter

Proyek latihan pemrograman Python, Computer Vision, dan Hand Tracking menggunakan OpenCV dan MediaPipe.

---

## 📁 Struktur Direktori

```text
belajar python/
├── main.py                      # RetroLens Filter & Hand Landmark Portal
├── hand_tracking.py             # Script hand tracking dasar dengan MediaPipe
├── hand_landmarker.task         # Model MediaPipe Hand Landmarker
├── selfie_segmenter.tflite      # Model segmentasi latar belakang (Galaxy filter)
├── requirements.txt             # Daftar dependensi modul
└── README.md                    # Dokumentasi panduan
```

---

## 🚀 Cara Menjalankan

1. **Install dependensi:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Jalankan RetroLens Filter:**
   ```bash
   python main.py
   ```

3. **Jalankan Hand Tracking:**
   ```bash
   python hand_tracking.py
   ```
